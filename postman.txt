==================== AUTH (api.php) ====================

1. LOGIN (Firebase)
   POST http://localhost:8000/api/login
   Headers: Content-Type: application/json
   Body (raw, JSON):
   {
     "email": "admin@gmail.com",
     "password": "password123"
   }

2. REGISTER (Firebase)
   POST http://localhost:8000/api/register
   Headers: Content-Type: application/json
   Body (raw, JSON):
   {
     "email": "nouveau@gmail.com",
     "password": "motdepasse123",
     "nom": "Dupont",
     "prenom": "Jean"
   }

3. UNBLOCK (api.php)
   POST http://localhost:8000/api/unblock
   Headers: Content-Type: application/json
   Body (raw, JSON):
   {
     "email": "admin@gmail.com"
   }

4. SWAGGER TEST
   GET http://localhost:8000/api/swagger-test
   (pas de body)

==================== SIGNALEMENTS (web.php /api/) ====================

5. LISTE DES SIGNALEMENTS
   GET http://localhost:8000/api/signalements
   (pas de body)

6. HISTORIQUE D'UN SIGNALEMENT
   GET http://localhost:8000/api/signalements/{id}/history
   Exemple: http://localhost:8000/api/signalements/1/history
   (pas de body)

7. MODIFIER UN SIGNALEMENT
   PUT http://localhost:8000/api/signalements/{id}
   Exemple: http://localhost:8000/api/signalements/1
   Headers: Content-Type: application/json
   Body (raw, JSON):
   {
     "description": "Nid de poule réparé partiellement",
     "surface_m2": 20.0,
     "budget": 3000000,
     "id_entreprise": 1,
     "id_type_signalement": 1,
     "statut": "en_cours"
   }

8. STATISTIQUES SIGNALEMENTS
   GET http://localhost:8000/api/signalements/stats
   (pas de body)
   Filtres optionnels: ?start_date=2025-01-01&end_date=2026-12-31

9. STATISTIQUES DÉTAILLÉES
   GET http://localhost:8000/api/stats/detailed
   (pas de body)
   Filtres optionnels: ?start_date=2025-01-01&end_date=2026-12-31

==================== UTILISATEURS (web.php /api/) ====================

14. LISTE DES UTILISATEURS
    GET http://localhost:8000/api/utilisateurs
    (pas de body)

15. CRÉER UN UTILISATEUR
    POST http://localhost:8000/api/utilisateurs
    Headers: Content-Type: application/json
    Body (raw, JSON):
    {
      "email": "user@example.com",
      "password": "motdepasse123",
      "nom": "Rakoto",
      "prenom": "Hery",
      "id_role": 3
    }

16. MODIFIER UN UTILISATEUR
    PUT http://localhost:8000/api/utilisateurs/{id}
    Exemple: http://localhost:8000/api/utilisateurs/1
    Headers: Content-Type: application/json
    Body (raw, JSON):
    {
      "nom": "Rakoto",
      "prenom": "Hery",
      "id_role": 2,
      "bloque": false
    }

17. DÉBLOQUER UN UTILISATEUR (par ID)
    POST http://localhost:8000/api/utilisateurs/{id}/unblock
    Exemple: http://localhost:8000/api/utilisateurs/1/unblock
    (pas de body)

18. DÉBLOQUER UN UTILISATEUR (par email)
    POST http://localhost:8000/api/utilisateurs/unblock-by-email
    Headers: Content-Type: application/json
    Body (raw, JSON):
    {
      "email": "admin@gmail.com"
    }

19. SYNCHRONISER UTILISATEURS VERS FIREBASE
    POST http://localhost:8000/api/sync-users
    (pas de body)
